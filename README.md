# Student Management System

A complete web application for managing students and departments built with Java, Jakarta Servlet, JSP, JSTL, JDBC, and MySQL following MVC architecture.

## Technologies Used

- **Java 17** - Programming language
- **Jakarta Servlet API 6.0** - Web framework (Tomcat 10/11 compatible)
- **JSP + JSTL** - View layer with tag library
- **JDBC** - Database connectivity
- **MySQL 8.x** - Database
- **Maven** - Build and dependency management
- **Apache Tomcat 10 / 11** - Servlet container
- **HTML + CSS** - UI with responsive design

## Features

- Dashboard with statistics (total students, total departments, recent students)
- Student CRUD (Add, View, List, Edit, Delete)
- Department CRUD (Add, List, Edit, Delete)
- Search students by name, roll number, email, or department
- View student details
- Server-side validation with error messages
- Unique constraint handling (roll number, email, department name)
- Responsive modern UI

## Database Setup

1. Install MySQL 8.x and ensure it is running.

2. Open MySQL command line or any MySQL client (MySQL Workbench, DBeaver, etc.).

3. Run the schema file to create the database, tables, and sample data:

   ```sql
   SOURCE path/to/student-management-system/src/main/webapp/WEB-INF/schema.sql;
   ```

   Or log in to MySQL and run:

   ```bash
   mysql -u root -p < src/main/webapp/WEB-INF/schema.sql
   ```

4. Verify the database was created:

   ```sql
   USE student_management_db;
   SELECT * FROM students;
   SELECT * FROM departments;
   ```

5. **Set the database credentials** as environment variables (read by `DatabaseConfig.java`):

   ```bash
   export DB_USERNAME=root            # default: root
   export DB_PASSWORD=your_password   # default: empty
   # optional: export DB_URL=jdbc:mysql://localhost:3306/student_management_db
   ```

   In Eclipse, add them under *Run Configurations → Environment* for the Tomcat server.

## How to Import in Eclipse

### Prerequisites

- **Eclipse IDE for Enterprise Java and Web Developers** (2023-12 or later)
- **Apache Tomcat 10.1.x** or **Apache Tomcat 11.x**
- **MySQL 8.x** installed and running
- **Maven** (comes with Eclipse)

### Steps

1. **Open Eclipse**

2. **Import the project:**
   - `File → Import → Maven → Existing Maven Projects`
   - Click `Next`
   - Browse to the project root folder (`student-management-system`)
   - Make sure `pom.xml` is selected
   - Click `Finish`

3. **Configure Tomcat server:**
   - Open the `Servers` view (`Window → Show View → Servers`)
   - Right-click → `New → Server`
   - Select `Apache → Tomcat v10.1 Server` (or Tomcat v11)
   - Click `Next`
   - Browse to your Tomcat installation directory (the folder containing `bin`, `conf`, `lib`, `webapps`)
   - Click `Finish`

4. **Add the project to the server:**
   - In the `Servers` view, right-click the Tomcat server
   - Select `Add and Remove`
   - Move `student-management-system` from `Available` to `Configured`
   - Click `Finish`

5. **Run the project:**
   - Right-click the project → `Run As → Run on Server`
   - Select the Tomcat server you configured
   - Click `Finish`
   - The application will open in Eclipse's internal browser at: `http://localhost:8080/student-management-system/`

## Common Errors and Fixes

### Error 1: `Could not find or load main class org.apache.catalina.startup.Bootstrap`

**Cause:** Tomcat installation is invalid or Eclipse cannot find the Tomcat runtime.

**Fix:**
- Verify Tomcat is downloaded and extracted correctly
- In Eclipse, go to `Window → Preferences → Server → Runtime Environments`
- Edit the Tomcat runtime and verify the path points to the correct Tomcat folder (must contain `bin`, `conf`, `lib`, `webapps`)
- If the folder is correct, delete the server runtime and add it again

### Error 2: `The main resource set specified [...] is not a directory or war file`

**Cause:** Eclipse failed to publish the project properly to the server's deploy directory.

**Fix:**
1. Right-click the Tomcat server in `Servers` view → `Remove` (remove the project)
2. Right-click the server → `Clean...` → Clean Tomcat work directory
3. Delete the Eclipse server temp folder:
   ```
   {workspace}/.metadata/.plugins/org.eclipse.wst.server.core/tmp0/
   ```
4. Right-click project → `Maven → Update Project...`
5. Right-click the server → `Add and Remove` → add the project again
6. Start the server

### Error 3: `ClassNotFoundException: com.mysql.cj.jdbc.Driver`

**Cause:** MySQL JDBC driver is missing from the classpath.

**Fix:**
- Verify `pom.xml` contains the MySQL connector dependency
- Right-click project → `Maven → Update Project...` (check "Force Update")
- Check `Maven Dependencies` in `Project Explorer` - `mysql-connector-j` should be listed

### Error 4: `javax.servlet does not exist`

**Cause:** The project is using `javax.servlet.*` imports but running on Tomcat 10+ which uses `jakarta.servlet.*`.

**Fix:**
- Use `jakarta.servlet.*` instead of `javax.servlet.*` in all Java files
- Ensure `pom.xml` uses `jakarta.servlet-api` version 6.x, not `javax.servlet-api`
- Ensure Tomcat 10 or 11 is configured (not Tomcat 9)

### Error 5: `Access denied for user 'root'@'localhost'`

**Cause:** MySQL credentials in `DatabaseConfig.java` do not match your MySQL setup.

**Fix:**
- Set `DB_USERNAME` and `DB_PASSWORD` to match your MySQL credentials (see step 5)
- Restart the server

### Error 6: `Unknown database 'student_management_db'`

**Cause:** Database has not been created yet.

**Fix:**
- Run the `schema.sql` file to create the database and tables
- See [Database Setup](#database-setup) section above
